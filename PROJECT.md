# Project: RepBlaze

Repository: `prouddaddy880810-byte/repblaze`
Default branch: `main`

## Purpose
Help local businesses get found, get chosen, capture leads, follow up reliably, and measure what marketing produces customers.

## Launch path
Traffic source → landing page → audit/CTA → lead capture → Supabase → attribution → follow-up → customer outcome.

## Immediate success criteria
- Landing page clearly explains offer.
- Audit remains functional.
- Lead submission is confirmed by backend response.
- Leads persist in Supabase.
- Test leads are distinguishable.
- Source/campaign attribution is saved.
- Follow-up can be triggered and tracked.
